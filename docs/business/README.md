# 事業メモ（小さな第二の脳）

Claude Code は、会話が終わると中身を忘れます。覚えているのは、リポジトリに書いてあることだけです。
このフォルダは、お客さんの声と、決めたことを溜めておく場所です。

| ファイル | 何を書くか | いつ | 消してよいか |
|---|---|---|---|
| `hot.md` | 今の要約（40行まで） | `/inbox` を使うたびに Claude Code が作り直す | 古いものは消して入れ替える |
| `customer-voice.md` | お客さんが言ったこと。その人の言葉のまま | 話したら、その日のうちに | 消さない。書き足すだけ |
| `decisions.md` | 決めたこと・やめたこと。理由つき | 決めたとき | 消さない。書き足すだけ |

## 入れ方

お客さんとの会話のメモ・メール・LINE・議事録を、そのまま貼ります。

```
/inbox
（ここに貼る）
```

Claude Code が3つのファイルに振り分けます。言い換えずに、その人の言葉のまま残します。

## 読まれ方

`CLAUDE.md` に読む順番が書いてあります。毎回全部は読みません。

1. `hot.md`（今の要約）
2. 足りなければ `customer-voice.md` と `decisions.md`

## 公開リポジトリで気をつけること

- 人の名前は伏せる（「三鷹の塾の教室長Aさん」）
- メールアドレス・電話番号は書かない（書こうとすると止める層が止めます）
- 相手が公開を望まないことは書かない
