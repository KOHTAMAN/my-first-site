# 画面の型 ── 3行から、どう見た目が変わるか

`app/page.tsx` の上にある **4つの定数** を選び直すだけで、同じコードのまま別のアプリに見えます。
`/build` はここを選ぶだけです。**新しいCSSは書きません。**

```tsx
const TONE     = "pine";    // 色み
const DENSITY  = "normal";  // 密度
const LAYOUT   = "queue";   // 画面の型
const UNIT     = "件";      // 数え方
```

---

## 例1 ── 塾の問い合わせ管理

> 「今日返信すべき人が、一覧で分かるといい」

```tsx
const TONE = "pine"; const DENSITY = "normal"; const LAYOUT = "queue"; const UNIT = "件";
const CATEGORIES = ["LINE", "電話", "メール", "紹介"];
```

```
[ 9 ]未対応  [ 5 ]3日以上 放置  [ 14 ]全件
未対応（待たせている順）                    9 件
  吉田さん（高2）  夏期講習の残席を…   [9日][LINE] 08/12
  山口さん（小6）  料金表を送ってほし… [6日][電話] 08/15
```

**古い順に片づける**画面。放置日数が主役になります。

---

## 例2 ── リユース店の買取品

> 「どの品がどの段階で止まっているかが一覧で分かるといい」

```tsx
const TONE = "clay"; const DENSITY = "compact"; const LAYOUT = "stage"; const UNIT = "点";
const CATEGORIES = ["検品待ち", "撮影待ち", "値付け待ち", "出品待ち"];
```

```
[ 11 ]進行中  [ 5 ]7日以上 動きなし  [ 14 ]全点
検品待ち                                    3 点
  革ジャケット L      裏地に小さな穴    [9日]  08/12
撮影待ち                                    3 点
  電動ドリル セット    動作確認済み     [12日] 08/09
```

**段階ごとに束ねる**画面。区分がそのまま段階になり、行の中の区分バッジは消えます。

---

## 例3 ── 設備会社の点検予定

> 「今週行くべき現場が一覧で分かるといい」

```tsx
const TONE = "sea"; const DENSITY = "roomy"; const LAYOUT = "due"; const UNIT = "件";
const CATEGORIES = ["定期点検", "修理", "見積", "その他"];
```

```
[ 10 ]未完了  [ 2 ]期限切れ  [ 14 ]全件
● 期限が過ぎている                          2 件
  青葉台マンション 3F 空調   [6日 超過][定期点検] 08/15
● 今日・明日                                2 件
  第一ビル 給湯器            [今日][修理]       08/21
今週のうち                                  3 件
```

**期限で束ねる**画面。日付が「受けた日」ではなく「期限」の意味になります。
見本データの未来日は `ago(-3)`（3日後）のように**マイナス**で書きます。

## 選び方

| 3行目がこう書かれていたら | LAYOUT |
|---|---|
| 「待たせている」「返信していない」「溜まっている」「古い順」 | `queue` |
| 「どの段階」「どこまで進んだ」「止まっている」「進捗」 | `stage` |
| 「今週」「締切」「期限」「予定」「いつまでに」 | `due` |

| 業種 | TONE |
|---|---|
| 教育・サービス・その他 | `pine` |
| 士業・不動産・BtoB | `indigo` |
| 建設・工務店・現場仕事 | `clay` |
| 医療・介護・公共 | `sea` |
| 飲食・小売・美容 | `wine` |

| 2行目の件数 | DENSITY |
|---|---|
| 1日20件以上 / 月100件以上 | `compact` |
| ふつう | `normal` |
| 1日5件以下で、1件が重い（高額・長期） | `roomy` |
