## 1. このツールが解くこと

今日返信すべき問い合わせが1画面で分かり、**返信漏れがなくなる。**

## 2. 使う人と、使う場面

- 使う人: 〇〇進学ゼミ 三鷹校の田中教室長
- 🔮 いつ開くか: 朝、教室に着いてPCを開いた最初の5分。移動中にスマホでも
- 開いて最初にしたいこと: 一番古い未返信の人に、今すぐ連絡する

## 3. 画面（1つだけ）

1. **問い合わせを追加**（名前・流入元を入れて「追加」）
2. **未返信リスト**（古い順。何件あるかを見出しに出す）
3. 3日以上放置している人は**色を変えて**表示

## 4. データ項目

| 項目 | 型 | 必須 | 例 |
|---|---|---|---|
| 保護者名 | 文字列 | ○ | 佐藤さん（中2） |
| 流入元 | LINE / 電話 / HP | ○ | LINE |
| 問い合わせ日 | 日付 | ○ | 2026-08-18 |
| 返信済みか | true / false | ○ | false |

## 5. 操作（3つまで）

| # | 操作 | 何が起きるか |
|---|---|---|
| 1 | 追加する | 今日の日付で未返信リストの末尾に入る |
| 2 | 返信済みにする | リストから消える（データは残る） |
| 3 | （リロードする） | データが残っていることを確認できる |

## 6. やらないこと

- 決済・月謝の集金
- 保護者向けマイページ
- 複数教室の一括管理
- 問い合わせの自動取り込み（まず手入力で成立させる）
- ログイン（第3回で扱う）

## 7. 完成条件

- [x] 未返信の問い合わせが、古い順に並んで表示される
- [x] 「返信済み」を押すと、その人がリストから消える
- [x] **リロードしてもデータが残っている**

## 8. 保存方法

`localStorage` に1つのキーで保存する。キー名: `juku-inquiries`

※ 端末ごとの保存です。**複数人での共有・別端末からの閲覧は第3回**で扱います。

## 9. ダミーデータ

初回表示用に3件（佐藤さん・鈴木さん・高橋さん）。すべて架空です。
