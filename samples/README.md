# 記入例（サンプル）

**空欄のシートだけ渡されても、何をどこまで書けばいいか分かりません。**
このフォルダは「埋まっているとこう見える」を示すためのものです。

| ファイル | 対応する本体 |
|---|---|
| `CLAUDE.sample.md` | ルート直下の `CLAUDE.md` |
| `01_customer.sample.md` | `docs/01_customer.md` |
| `02_onepager.sample.md` | `docs/02_onepager.md` |

題材はすべて共通で、**「地域の学習塾向け・体験授業の問い合わせ管理」**。
受講者と同じくらいの規模感で、次の全部が1本の題材で説明できるものを選んでいます。

- ホワイトスペースの5類型のうち **B（市場が小さい）**
- 出口①②③のすべて（**②が「下の経路」になる**わかりやすい例）
- DIY競合（塾長が自分でChatGPTに返信文を作らせる）
- 「選ばれる理由」を **埋め込み** で書く例
- **やらないこと**を3つ書く例

## 使い方

### 受講者
書き方に迷ったら開いてください。**そのまま真似せず、自分の顧客で書き換えてください。**
`CLAUDE.sample.md` の末尾に「この記入例だと、どんな出力になるか」の対応表があります。

### 講師・サポート
- 当日のデモに使えます（埋まっている状態と空の状態で、出力がどう変わるかを見せる）
- キットの動作確認にも使えます。`01_customer.sample.md` の中身を `docs/01_customer.md` に貼って
  配布プロンプトを流すと、テンプレートが正しく反応するか一通り確認できます

## 注意

サンプルの塾名・人名はすべて**架空**です。実在の団体とは関係ありません。
実データ（実在する人の氏名・連絡先）は、Publicリポジトリに絶対に入れないでください。
