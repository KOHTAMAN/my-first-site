# ここから下は Claude Code が埋めた仮説

## 解く課題

🔮 **今その人はどうやっているか**: 問い合わせが来るたびに紙のノートへ転記し、
夜に教室を閉めてから思い出して返信していると思われる。
　→ 確かめ方: 「問い合わせが来たら、まず何をされていますか？」

🔮 **かかっている時間 / 費用**: 1件あたり返信15分 × 月30件 ＝ **月7.5時間**程度。
返信漏れが月2〜3件あるとすると、体験→入会率5割・月謝2.5万円で **月2.5万円前後の機会損失**。
　→ 確かめ方: 「1件返信するのに、だいたい何分かかっていますか？ 月に何件くらい来ますか？」

## なぜ今まで誰も作らなかったのか

🔮 **市場が小さい**（5類型のB）。
1校が出せるのは月3,000〜5,000円程度と思われ、受託開発だと初期300万円かかるため、
システム会社は1校単位を相手にせず、大手チェーン向けの高機能製品しか作ってこなかった可能性が高い。
　→ 確かめ方: 「今、教室の管理系で月いくら払っていますか？」

## 出口の3点

### 🔮 ① 誰が払うか

払う人は**教室長本人**（各校に決裁権があり、本部承認は不要な可能性が高い）。
集客（チラシ・ポータル掲載）には予算を張る商習慣があると思われるが、
**「管理ツールに払う」文化は薄い**可能性が高い。
　→ 確かめ方: 「集客には月いくらかけていますか？ 管理系のツールにはお金を使っていますか？」
　→ もしそうなら、**管理ツールとしてではなく「集客の取りこぼしを減らすもの」として売る**必要があります。

### 🔮 ② どう届くか　← **最優先で確かめること**

塾長同士の**紹介**、地域の学習塾協会の会合、教材会社の営業経由。
つまり **下の経路**（紹介・口コミ・業界内の直接接触）で動いている市場と思われる。
「塾 問い合わせ管理」で検索する人はほぼいない（そもそも課題を言語化していないため）。
　→ 確かめ方: 「新しい道具って、どこで知ることが多いですか？」

**幸い、あなたは前職の接点があるので下の経路が使えます。ここが取り分です。**

### ✅ ③ 受け取れるか

教育サービスは決済代行の禁止業種・要審査業種に**該当しません**（規約の禁止業種一覧で確認可能）。
ただし保護者の氏名・連絡先を扱うため、プライバシーポリシーの掲示は必要です。
　→ これは規約を読めば確定するので、🔮 を外してあります。

## 競合

🔮 **既存の競合**: 塾向け生徒管理システム（月3万円〜・高機能すぎて使われない）、
Googleフォーム＋スプレッドシート（無料だが自分で組めない）

**DIY競合**: 田中さんが自分でChatGPTに返信文を作らせる。
→ **返信の質は上がるが、「誰に返したか」の管理は解決しない。**ここが残る差です。

🔮 **選ばれる理由**: **埋め込み。**
毎朝スマホで「今日返す人」を見る動線に入るため、抜くと元の状態に戻ってしまう。
　→ 確かめ方: 「朝、教室に来て最初に何を見ますか？」

## 🔮 やらないこと（3つ）

- **決済・月謝の集金機能** — 既存の口座振替を置き換えない
- **保護者向けマイページ** — 保護者に新しいアプリを入れさせない
- **複数教室の一括管理** — まず1校で成立させる
