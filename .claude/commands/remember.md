---
description: 同じことを2回言ったら、1行の決まりにして残す
---

ユーザーが Claude Code に直させたこと・念を押したことを、**次の会話でも守られる1行**にして残してください。

残したいこと: $ARGUMENTS

（空なら、この会話でユーザーが2回以上言ったこと・直させたことを探し、候補を最大3つ見せて、どれを残すか聞く）

## 手順

1. 1行にする。「〜しない」「〜は〜にする」の形で、理由を（）で短く添える
   - 良い: 「ボタンは1つだけにする（迷わせないため）」
   - 悪い: 「わかりやすいデザインにする」（何をすればいいか決まらない）
2. どの層に置くかを決め、ユーザーに1行で伝える

   | 破られたときの痛さ | 置き場所 |
   |---|---|
   | 小さい（言葉づかい・書き方・見た目の好み） | `CLAUDE.md` の「決まり（2回言ったこと）」に1行足す |
   | 言葉で決められる（この言葉は使わない） | `.claude/harness.json` の「使わない言葉」に足す。以後、画面を直すたびに自動で検査される |
   | 大きい（鍵・削除・お客さんの情報） | 書き足さずに止まる。「止める層（.claude/hooks/stop.mjs）に入れる候補です」と伝える |

3. 既に同じ意味の行があれば足さない。そのことを伝える
4. 足した行に日付を付ける（例: `- 11/5 ボタンは1つだけにする（迷わせないため）`）

## やらないこと

- 1回しか言われていないことを、勝手に決まりにしない
- 既存の行を消したり、まとめ直したりしない（ユーザーに頼まれたときだけ）
- CLAUDE.md と .claude/harness.json 以外は変更しない
