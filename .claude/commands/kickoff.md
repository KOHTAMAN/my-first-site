`docs/01_customer.md` の「はじめの3行」を読んで、**残りをあなたが仮説で埋めてください。**

受講者は今、顧客に会いに行く時間がありません。
だから **あなたが仮説を立て、それを「確かめるべきことのリスト」に変換する** のが、このコマンドの仕事です。

---

## 絶対に守ること

### 1. 質問を返さない

3行が空欄でも、書き方が雑でも、**聞き返さずに進めてください。**
情報が足りないところは、**もっともらしい仮説で埋める**のが正しい動作です。

3行すべてが空の場合だけ、「どんな仕事をされていますか？」と**1問だけ**聞いて、その答えから組み立ててください。

### 2. 仮説には必ず 🔮 を付ける

受講者が書いたこと（事実）と、あなたが埋めたこと（仮説）を、**見た目で区別できるようにしてください。**

- 受講者が書いた → そのまま。マークなし
- あなたが埋めた → 行頭に `🔮` を付ける

### 3. 仮説には「確かめ方」をセットで書く

🔮 の項目には、**その顧客に何と聞けば確かめられるか**を1行添えてください。

```
🔮 かかっている時間: 1件あたり15分、月30件で7.5時間
   → 確かめ方: 「1件返信するのに、だいたい何分かかっていますか？」
```

### 4. 断定しない言葉づかいにする

「〜です」ではなく「〜と思われる」「〜の可能性が高い」で書いてください。
受講者が仮説を事実だと勘違いすると、講義の趣旨と正反対になります。

### 5. 「1画面の管理ツール」の形に落とす

このテンプレートで作れるのは、**1種類のデータを、登録して・探して・状態を変える**ツールだけです。

| ✓ 作れる | ✕ 作れない（今回は扱わない） |
|---|---|
| 問い合わせ・顧客・案件・在庫の**管理** | メディア・記事サイト |
| 作業や訪問の**記録と進捗** | マッチング・掲示板・SNS |
| 「誰の・いつまで・終わったか」の**一覧** | 決済・ログイン・お客さん側からの入力 |

受講者の題材が右側を含んでいたら、**断らずに、その中の「自分が管理する部分」だけに絞ってください。**

- メディアを作りたい → **記事の進捗管理**（誰が書く・締切・公開済みか）
- ネットショップ → **注文の対応状況**
- 予約サイト → **予約の受付管理**（自分が入力する形にする）

絞ったときは、**なぜ絞ったかを1行**添えてください。

> 「今日は『記事の進捗管理』に絞ります。記事サイトそのものは第2回で扱うためです。」

## 最初に：3行の質を1回だけ評価する

仮説を作る前に、3行を見て**いちばん弱い1つ**を指摘してください。**止めずに、指摘してから続けます。**

| 行 | 強い状態 | 弱いときに起きること |
|---|---|---|
| 1. 誰 | **呼べる名前**がある（「〇〇工務店の田中さん」） | 顧客像がぼやけ、文言が一般論になる |
| 2. 困りごと | **何を・頻度・時間**が入っている（「月5件・1件2時間」） | **データ項目と操作が決まらない**。ここが最重要 |
| 3. あれば助かる | **状態**で書かれている（「〜が分かる」） | **完成条件が決まらない** |

指摘は次の形で、**1つだけ**。長く書かないこと。

> 「2行目に『月に何件』『1件何分』を足すと、作る画面がもっと具体的になります。
>  今回はこちらで数字を仮に置いて進めます（🔮 が付きます）。」

**そのうえで必ず先に進んでください。**書き直しを待たないこと。

### 数字が無い場合の埋め方

2行目に数字が無ければ、**業種から自然な数字を仮に置いて 🔮 を付ける**。
「不明」で逃げないこと。数字が入らないと、この先の要件定義書が作れません。

## 埋める項目

`docs/01_customer.md` の `<!-- ▼▼ /kickoff の出力はここに入ります ▼▼ -->` の中に書き込みます。

| # | 項目 | 埋め方の指針 |
|---|---|---|
| 1 | **今その人はどうやっているか** | 手作業・エクセル・紙・誰かに頼む のどれかから、業種的に自然なものを選ぶ |
| 2 | **かかっている時間 / 費用** | 具体的な数字を置く。「1件◯分 × 月◯件」の形にする |
| 3 | **なぜ今まで誰も作らなかったのか** | 5類型（データが散っている／市場が小さい／量が多すぎる／判断が非定型／n=1すぎる）から**1つ選び、理由を書く** |
| 4 | **① 誰が払うか** | 「使う人」と「払う人」が違う可能性を必ず検討する。その相手に予算を張る商習慣があるかも書く |
| 5 | **② どう届くか** | その業界が実際に使っている経路を推定し、**上の経路（検索・広告・DM・SNS）か、下の経路（紹介・口コミ・既存顧客・業界内）か**を明示する |
| 6 | **③ 受け取れるか** | 決済の禁止・要審査業種（投資/金融・医療・健康・サプリ・法律相談・暗号資産・ギャンブル・アダルト・情報商材）に該当するかを判定する |
| 7 | **競合とDIY競合** | 既存競合に加えて、**顧客が自分でAIに作らせる場合**を必ず書く |
| 8 | **選ばれる理由** | データ／責任／時間／埋め込み の4つのどれかで書く。**機能で書かない** |
| 9 | **やらないこと（3つ）** | この題材で作りたくなるが今回はやらないことを3つ。ここが空だと機能が膨らむ |
